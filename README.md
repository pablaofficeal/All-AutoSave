# 🎬 Premiere AutoSave Pro

Автосохранение проектов Adobe Premiere Pro + поддержка кастомных скриптов.  
Разработано с заботой о твоих нервах, чтобы ты не потерял проект из-за краша 😎

## 📦 Возможности

- ⏱️ Автоматическое сохранение проекта через заданный интервал
- ⚙️ Поддержка кастомных Python-скриптов (автоматизация чего угодно)
- 🔔 Уведомления о сохранении проекта
- 🧠 Логирование всех действий
- 🖼️ Удобный и красивый интерфейс на `customtkinter`

## 🛠️ Установка и запуск

1. Клонируй репу:
   ```bash
   git clone https://github.com/pablaofficeal/All-AutoSave.git
   cd All-AutoSave

Установи зависимости (если Python сам не предложит):

   ```bash
pip install customtkinter pyautogui plyer
```
Запусти:

   ```bash
python main.py
```

Если ты юзаешь .exe версию — просто открой PremiereAutoSavePro.exe.

🧩 Как юзать кастомные скрипты?
Перейди в вкладку Кастомный скрипт

Нажми Загрузить скрипт

Выбери .py файл с методом execute() внутри:

```python
# Пример кастомного скрипта
def execute():
    print("Выполняется кастомная логика")
```
Укажи интервал — и жми старт!

📁 Логи
Все логи сохраняются в папке logs/ рядом с файлом.
